Plataforma · GBA

LuaStudio GBA · C API

Editor de projetos C para Game Boy Advance. O fluxo compila fontes C com GNU Arm Embedded/devkitARM e produz ROM .gba.

Fluxo de trabalho

#include "gba.h"

int main(void) {
    gba_init();
    gfx_init(3);
    gfx_clear(BLACK);
    gfx_text(8, 8, "Ola, GBA!", WHITE);
    while (1) {
        vsync();
        key_poll();
    }
}

O editor cria projetos em Documentos/GBA//, com src/, assets/ e gba_project.json. O Python orquestra a compilação, mas não contém o compilador ARM: é necessário arm-none-eabi-gcc, objcopy e size, ou a ponte Termux/Debian no Android.

Configuração de build

OpçãoDescrição
modeModo gráfico/asset 3, 4 ou 0.
optOtimização -O2, -O3 ou -Os.
ltoAtiva Link Time Optimization.
thumbGera código Thumb quando habilitado.
allow_floatRebaixa o diagnóstico de float/double de erro para aviso.
warn_divisionAtiva aviso de divisão/mod por variável.
toolchain_dirDiretório bin do toolchain.
bridge_enabled / bridge_urlCompilação via ponte local Termux/Debian.

Regras e diagnósticos

CódigoRegra
GBA001Cabeçalhos de libc selecionados são proibidos no runtime freestanding.
GBA002float/double são bloqueados por padrão; use fixed 24.8.
GBA003Funções comuns de libc não estão disponíveis; há alternativas próprias.
GBA004Arrays locais acima de 1 KiB geram erro/alerta de pilha.
GBA005VLA proibido.
GBA006Divisão e módulo por variável podem ser caros.

Após o link, o build analisa ROM, IWRAM (32 KiB) e EWRAM (256 KiB), emitindo avisos de memória. O pipeline usa cache incremental por hash.

API C do Game Boy Advance

Referência alinhada diretamente ao cabeçalho luastudio/gba/runtime/gba.h incluído no pacote da engine. Esta página documenta os símbolos realmente declarados no runtime, sem acrescentar funções presumidas.

240 × 160Resolução nativa
ARM7TDMICPU do hardware
Mode 3 / 4Bitmap documentado
gba.hFonte de verdade

Compatibilidade e modelo de execução

O cabeçalho oferece tipos inteiros explícitos, ponto fixo 24.8, acesso direto aos registradores, vídeo bitmap e tile, sprites, áudio PSG/PCM, DMA e rotinas de memória. O runtime também possui caminho GBA_HOST para testes no computador. A implementação e o linker script continuam sendo a autoridade final sobre o que pode ser executado no hardware.

Começo rápido

#include "gba.h"

int main(void) {
    gba_init();              // inicializa VBlank e som
    gfx_init(3);              // bitmap 240x160, RGB15
    while (1) {
        key_poll();
        gfx_clear(BLACK);
        if (key_held(KEY_A))
            gfx_text(72, 72, "LUA STUDIO", WHITE);
        vsync();
    }
}

Referência por subsistema

Inicialização e sincronização

gba_init() inicializa o runtime (deve ser chamada primeiro); vsync() aguarda o VBlank; frame_count() retorna o total de VBlanks desde a inicialização.

Entrada

Chame key_poll() a cada frame antes de consultar o estado. key_held(k), key_pressed(k) e key_released(k) consultam pressionado, recém-pressionado e recém-liberado. key_axis_x() e key_axis_y() retornam eixos digitais do direcional.

Constantes: KEY_A, KEY_B, KEY_SELECT, KEY_START, KEY_RIGHT, KEY_LEFT, KEY_UP, KEY_DOWN, KEY_R e KEY_L.

Vídeo bitmap e desenho

gfx_init(3) seleciona modo 3 (RGB15, buffer único); gfx_init(4) seleciona modo 4 (índices de paleta, páginas alternadas). Use gfx_flip() no modo 4, preferencialmente após vsync(). A API inclui pixel, leitura, linhas, retângulos, círculos, blit e paleta.

Texto e tilemaps

gfx_text, gfx_text_bg, gfx_int e gfx_hex desenham texto/números no bitmap. bg_tiles_4bpp, bg_map e bg_config configuram fundos em tiles; txt_init, txt_print e txt_clear gerenciam texto baseado em tiles.

Sprites e OAM

spr_init() prepara os 128 sprites; spr_set configura um sprite e spr_hide o oculta. spr_tiles e spr_palette carregam dados. spr_flush() envia o shadow-OAM; faça isso no VBlank. Tamanhos e flags: SPR_8x8, SPR_16x16, SPR_32x32, SPR_64x64, SPR_HFLIP e SPR_VFLIP.

Áudio

Música: snd_init, snd_play, snd_stop, snd_pause, snd_playing. PCM mono 8-bit assinado: snd_pcm_play e snd_pcm_stop. Efeitos PSG: snd_beep (canais 0–3).

Matemática, memória e compressão

FIX/FIX_INT e fix_mul trabalham com ponto fixo 24.8. fsin/fcos usam tabela de 256 posições. Há xorshift (rand_u32, rand_seed, rand_range), isqrt32, macros ABS/MIN/MAX/CLAMP, cópias e preenchimentos por CPU/DMA e descompressão BIOS LZ77.

Cuidados importantes

  • Não trate gfx_flip() como operação válida no modo 3; ela é destinada ao modo 4.
  • Os índices de paleta do modo 4 não são cores RGB15 diretas.
  • Os argumentos de largura, altura, tamanho e ponteiros de assets precisam respeitar o formato esperado pelo modo de vídeo e pela rotina usada.
  • As macros de memória e registradores são acesso de baixo nível ao hardware; use apenas quando compreender o mapa de memória do GBA.
  • EWRAM_BSS está documentado no cabeçalho como seção não zerada; não assuma inicialização automática dos dados.

dualsense.trigger

Gatilhos adaptativos L2/R2: efeitos de resistência, vibração e presets.

Exemplo rápido

dualsense.trigger.weapon("R2", 0.4, 0.7, 1.0)
dualsense.trigger.preset("L2", "heartbeat")

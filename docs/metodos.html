Métodos de objeto

Chamados com dois-pontos: obj:Metodo(args). Alguns só fazem sentido em certas classes (indicado pela categoria).

Geral

# Set

obj:Set([spec])

Aplica uma tabela de propriedades de uma vez e retorna o objeto.

# Destroy

obj:Destroy()

Remove o objeto da cena.

Usado em:e3:Destroy() -- remove o grupo todo 27_instanciar_cenas

Transformação

# Move

obj:Move([dx = 0], [dy = 0], [dz = 0])

Move o objeto de forma relativa (dx, dy, dz).

Usado em:plataforma:Move(70 * dir * dt, 0) 28_fisica_real

# MoveTo

obj:MoveTo([x = 0], [y = 0], [z = 0])

Move o objeto para uma posição absoluta.

# Rotate

obj:Rotate([d = 0], [dy], [dz])

Gira o objeto (graus; em 3D aceita dy, dz).

Usado em:app.find("Cubo"):Rotate(50*dt, 70*dt, 0) 02_cena_3d

# LayerMove

obj:LayerMove([n = 0])

Define a camada de renderização (RenderLayer).

# GetPosition

obj:GetPosition()

Retorna a posição como vetor.

# SetScale

obj:SetScale([x = 1], [y], [z])

Define a escala (x, y, z).

# GetScale

obj:GetScale()

Retorna a escala como vetor.

# Stretch

obj:Stretch([sx = 1], [sy = 1])

Estica o objeto por fatores sx, sy.

Usado em:caixa:Stretch(sx, sy) 04_fisica_e_escala

# Flip

obj:Flip([fx], [fy], [fz])

Espelha o objeto nos eixos X, Y e/ou Z.

Usado em:caixa:Flip(math.floor(t) % 2 == 0, false) 04_fisica_e_escala

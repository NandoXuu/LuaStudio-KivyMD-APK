Eventos

Callbacks atribuídos como propriedades: obj.OnClick = function(self) ... end ou dentro da tabela de create.

EventoAssinaturaQuando
OnClickfunction(self)Chamado quando o objeto é clicado/tocado.
OnChangefunction(self, valor)Slider/toggle/textbox: o valor mudou.
OnUpdatefunction(self, dt, t)Chamado todo frame para este objeto (t = tempo do mundo, ou da UI se o objeto for de UI).
OnMouseEnterfunction(self)O ponteiro entrou na área do objeto.
OnMouseExitfunction(self)O ponteiro saiu da área do objeto.
OnSubmitfunction(self, texto)TextBox: o usuário pressionou Enter.
OnFocusfunction(self)O campo de texto ganhou foco.
OnBlurfunction(self)O campo de texto perdeu foco.
OnDrawfunction(self, draw)Canvas: desenhe aqui usando o contexto draw, todo frame.
OnLinkClickfunction(self, url)Texto rico: um link foi clicado (recebe a URL).
OnAnimEndfunction(self)A animação de spritesheet terminou.
OnCollisionEnterfunction(self, outro, contato)Física: começou uma colisão. contato = { Point, Normal, Impulse, Penetration, Speed }.
OnCollisionStayfunction(self, outro, contato)Física: a colisão continua a cada passo.
OnCollisionExitfunction(self, outro, contato)Física: a colisão terminou.
OnTriggerEnterfunction(self, outro)Física: algo entrou numa área/gatilho.
OnTriggerStayfunction(self, outro)Física: algo permanece na área.
OnTriggerExitfunction(self, outro)Física: algo saiu da área.
OnCollidefunction(self, outro[, contato])Atalho disparado junto com OnCollisionEnter (e pelo sistema de física simples).
OnAreaEnterfunction(self, outro)Entrou numa Area2D.
OnAreaExitfunction(self, outro)Saiu de uma Area2D.

Tabela de contato

Nos eventos OnCollision* o terceiro argumento é uma tabela com Point (vetor), Normal (vetor, apontando para fora do objeto atual), Impulse, Penetration e Speed. Eventos OnTrigger* recebem só (self, outro).

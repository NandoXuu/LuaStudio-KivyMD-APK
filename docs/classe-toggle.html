create.toggle

Interruptor liga/desliga com Checked e OnChange.

Como criar

create.toggle.Nome = { Position = {20, 20} }      -- forma mais comum
local obj = create.toggle.Nome{ Size = {200, 60} } -- retorna o objeto
local obj2 = create("toggle", { Name = "Outro" })

app.find("Nome").Visible = false          -- acessar depois

Todas as classes compartilham as propriedades comuns (Position, Size, Color, Visible…).

Eventos

EventoAssinaturaQuando
OnChangefunction(self, valor)Slider/toggle/textbox: o valor mudou.
OnUpdatefunction(self, dt, t)Chamado todo frame para este objeto (t = tempo do mundo, ou da UI se o objeto for de UI).

Núcleo

Scenes / scene

Registro e troca de cenas, além de instanciar cenas-prefab a partir de arquivos .lua.

Também acessível como: scenes scene

Exemplo rápido

Scenes.register("menu", function() create.label.T = { Text = "Menu" } end)
Scenes.load("menu", 0.4)   -- com fade de 0.4s

register current has load instantiate instances

# register

Scenes.register([name], [fn])

Registra uma cena nomeada: uma função que cria seus objetos.

Usado em:Scenes.register("menu", function() 06_cenas_e_particulas

# current

Scenes.current()

Nome da cena atual.

# has

Scenes.has([name])

Retorna true se existe uma cena registrada com esse nome.

# load

Scenes.load([name], [fade = 0])

Troca para a cena registrada, opcionalmente com fade (segundos).

Usado em:jogar.OnClick = function() Scenes.load("jogo", 0.4) end -- 0.4s = fade preto de ida e volta 06_cenas_e_particulas

# instantiate

Scenes.instantiate([name], [overrides])

Instancia uma cena-prefab (arquivo .lua que devolve { Objects = {...} }) com overrides opcionais.

Usado em:local e1 = scene.instantiate("Enemy", { Position = {300, 200} }) 27_instanciar_cenas

# instances

Scenes.instances()

Lista as instâncias de prefabs vivas.

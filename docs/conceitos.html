Conceitos

O modelo mental da engine em cinco minutos.

A global create

Todo objeto nasce de create.<classe>.<Nome>. As três formas abaixo são equivalentes:

create.button.Jogar = { Text = "Jogar", Position = {20, 20} }
create.button{ Name = "Jogar", Text = "Jogar" }
create("button", { Name = "Jogar", Text = "Jogar" })

Depois, acesse por app.find("Jogar") ou pelo valor retornado. Atribuir uma propriedade de um objeto existente a altera na hora: create.button.Jogar.Text = "Ok". Classes inválidas geram erro listando as válidas.

Coordenadas

Em 2D a origem é o canto superior esquerdo e y cresce para baixo. Position e Size são vetores {x, y}. Use Anchor e AnchorOffset para ancorar, e IgnoreCamera = true para HUD fixo quando há camera2d.

Cores

Aceitam nome, hexadecimal (#rgb, #rrggbb, #rrggbbaa) ou tabela {r, g, b[, a]} (valores 0–1 ou 0–255). Nomes disponíveis:

whiteblackredgreenblueyelloworangepurplecyanpinkgraygreydarktransparent

Tempo do mundo vs. UI

A engine mantém dois relógios: o mundo (física, animações, onUpdate, timer.after) e a UI (onUIUpdate, timer.afterUI). environment.setConfig{TimeScale=...} e pause.world() afetam só o mundo — assim o menu continua responsivo em câmera lenta.

pause.world()                       -- congela o mundo
onUIUpdate(function()                -- continua rodando
  if input.isPressed("Pause") then pause.toggle() end
end)

Cenas e módulos

Scenes.register(nome, fn) + Scenes.load(nome, fade) trocam de cena; Scenes.instantiate cria prefabs a partir de arquivos .lua que devolvem { Objects = {...} }. Para dividir código use require.

Dicas e armadilhas

  • wait() não pausa o script — use timer.after.
  • Valores NaN/infinito são sanitizados antes de chegar ao renderizador.
  • Lua aqui é um subconjunto: veja a biblioteca padrão disponível.
  • Em Pydroid, não importe pygame antes do Kivy; o áudio carrega o mixer sob demanda.
  • Use graphics.setTextureFilter("nearest") para pixel art.

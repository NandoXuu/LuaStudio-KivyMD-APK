mixer

Barramentos de volume (Master, SFX...), mute, roteamento e conversão dB.

Exemplo rápido

mixer.setVolume("Master", 0.8)
mixer.setMute("SFX", false)

setVolume setVolumeDB setMute route dbToLinear linearToDB

# setVolume

mixer.setVolume([bus = 'Master'], [vol = 1])

Volume linear (0–1) de um barramento (Master, SFX, Music...).

# setVolumeDB

mixer.setVolumeDB([bus = 'Master'], [db = 0])

Volume do barramento em decibéis.

# setMute

mixer.setMute([bus = 'Master'], [muted = true])

Muta ou desmuta um barramento.

# route

mixer.route([source = ''], [bus = 'SFX'])

Direciona uma fonte de áudio para um barramento.

# dbToLinear

mixer.dbToLinear([db = 0])

Converte dB em ganho linear.

# linearToDB

mixer.linearToDB([lin = 1])

Converte ganho linear em dB.

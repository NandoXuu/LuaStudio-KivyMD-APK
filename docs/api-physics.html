Física

physics

Motor de física 2D de corpos rígidos: gravidade, mundo, juntas, materiais, raycast e debug.

Exemplo rápido

physics.world.Gravity = {0, 980}
local bola = create.frame.Bola{ Size = {40, 40}, Radius = 20 }
bola:EnablePhysics{ Type = "dynamic", Restitution = 0.5 }
bola:AddCollider{ Shape = "circle" }

Corpos e colisores

Para um objeto participar da simulação use os métodos de objeto EnablePhysics e AddCollider; os callbacks de colisão estão em Eventos. O exemplo completo é o 28 · Física real.

physics.debug = { Colliders = true, Contacts = true, Velocity = true }
local hit, ponto = physics.raycast(0, 0, 300, 300)
if hit then print(hit.Name, ponto.x, ponto.y) end

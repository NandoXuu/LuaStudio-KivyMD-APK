Sistema de plugins

Plugins estendem a IDE e a engine sem substituir arquivos: escutam eventos e registram extensões. Cada plugin recebe uma instância plugin (PluginAPI) injetada automaticamente.

Eventos padrão

engine_start engine_stop project_open project_close project_save editor_ready before_run after_run script_changed

Plugins podem escutar e emitir qualquer nome de evento, inclusive personalizados.

Tipos de extensão

menu panel editor_feature lua_api shader renderer_hook asset_importer

PluginAPI

MétodoDescrição
plugin.on(event_name, callback)Escuta um evento.
plugin.off(event_name, callback)Remove um listener.
plugin.emit(event_name)Dispara um evento.
plugin.register_menu(name, value)Registra item de menu.
plugin.register_panel(name, value)Registra um painel.
plugin.register_editor_feature(name, value)Registra recurso do editor.
plugin.register_lua_api(name, value)Registra uma API Lua.
plugin.register_shader(name, value)Registra um shader.
plugin.register_renderer_hook(name, value)Registra gancho de renderização.
plugin.register_event(event_name, callback)Registra callback para um evento.
plugin.register_extension(kind, name, value)Registro genérico por tipo.

Também disponível: plugin.engine — a instância da IDE (usada para log, etc.).

plugin/python/main.py

# -*- coding: utf-8 -*-
"""Plugin de exemplo para o sistema de plugins da LuaStudio.

A variavel `plugin` (instancia de PluginAPI) e injetada automaticamente
pelo loader antes deste arquivo ser executado.
"""


def _on_editor_ready(**kwargs):
    app = plugin.engine  # a LuaStudioApp, injetada como engine_context
    if app is not None:
        app.log("[AutoComplete] editor pronto - plugin ativo")
    plugin.register_menu("autocomplete_toggle", {
        "label": "AutoComplete: ligado",
    })


def _on_before_run(**kwargs):
    app = plugin.engine
    if app is not None:
        app.log("[AutoComplete] projeto vai rodar - nada a fazer aqui, so um exemplo de hook")


plugin.on("editor_ready", _on_editor_ready)
plugin.on("before_run", _on_before_run)

Estrutura do pacote: manifest.json + plugin/python/main.py. Exemplo completo em examples/plugins/autocomplete_example.lpkg.

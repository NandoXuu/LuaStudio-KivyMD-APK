## About

LuaStudio is an experimental mobile development environment focused on Lua scripting and game development.

The project aims to bring game development tools and scripting capabilities to Android through an integrated editor and development environment.

## Features

- Lua scripting environment
- Android-first interface
- Project creation and management
- Game development tools
- 2D and experimental 3D development
- Graphics, shaders, and visual effects
- Audio and input APIs
- Built-in examples and API documentation

Features and APIs may change during beta development.

## Installation

1. Download the APK from GitHub Releases.
2. Open the APK on your Android device.
3. Allow installation from the selected source if Android requests it.
4. Install and launch LuaStudio.

## About

LuaStudio is an experimental, mobile-first development environment focused on Lua scripting and game development.

The project aims to make programming more accessible on Android by providing an integrated editor, project tools, and an environment for experimenting with scripts and game systems.

LuaStudio is actively developed and currently available as a beta.

## Features

- Lua script editor
- Android-first development experience
- Project creation and management
- Integrated development interface
- Game development experimentation
- Built-in examples and development tools
- Touch-friendly workflow
- Experimental engine features

Some features are experimental and may change between releases.

### Installation

1. Open the Releases page.
2. Download the APK from the latest release.
3. Open the APK on your Android device.
4. Allow installation from the selected source if Android requests it.
5. Install and launch LuaStudio.

## Development

LuaStudio is built using Python, Kivy, and KivyMD, with Lua scripting support.

The project is primarily designed for Android development and testing.
